# Causal Studio · Windows 因果发现工作台

## macOS 安装包

macOS 15 及以上提供 Apple 芯片和 Intel 两种构建。安装、云端打包和签名说明见 [MACOS.md](MACOS.md)。

## 0.5 更新：Stata 导入和统一规模上限

- 导入按钮支持 `.dta`（Stata）文件，以及原有 CSV / TSV / XLSX。可用 `examples/observational_demo.dta` 测试中文变量名。
- Stata 原始变量名、数值编码和日期保留；变量标签和值标签记录在导出 JSON 的来源信息中，不用标签替换数值。普通缺失、扩展缺失和空字符串按缺失值处理。
- 所有算法的输入上限统一为 **100,000 行、30 个选中分析变量**；取消 RESIT 和非线性时序检验原来的 3,000 行、10 变量限制。导入可包含更多列，分析时最多选 30 列。
- 文件大小上限调整到 512 MB，避免 100,000 × 30 的 CSV 被旧 50 MB 限制挡住。超出行数会明确报错，不静默截断。
- 扩容表示允许导入、选择和提交全量数据，不代表所有算法都能在任意电脑上完成该规模计算。RESIT 的核检验、GPDC 等非线性方法可能需要大量内存和时间；运行时可取消，不会自动抽样。

## 0.4 更新：非线性、非高斯时序与潜在混杂

- 新增 **RESIT**：随机森林回归（100 棵树、最大深度 4）+ HSIC；适用于连续变量的非线性加性噪声模型，无潜在共同原因。
- 新增 **VARLiNGAM**：线性非高斯时间序列的同期和滞后结构；界面的最大滞后用作固定 VAR 阶数，系数阈值用于显示过滤。
- 新增 **LPCMCI（实验性）**：允许时间序列存在未观测共同原因；保留 PAG 端点，不把双箭头解释为双向因果。
- PCMCI / PCMCI+ / LPCMCI 均可通过“时序检验”选择 ParCorr、GPDC 或 CMIknn。GPDC 依赖加性噪声模型；CMIknn 估计条件互信息，不提供效应的正负方向。
- 非线性检验可设置 99–9999 次重采样，默认 199 次；次数越多，p 值分辨率越细，计算越慢。PCMCI 的 BH-FDR 可能需要更多重采样才能检出关系。
- 0.4 的非线性规模限制已在 0.5 取消；当前统一上限为 100,000 行、30 个选中变量，所有计算均可取消。
- LPCMCI 不作 FDR 校正，其 p 值是算法记录的最大检验 p 值，不能解释为方向显著性。
- 随机种子固定为 2026；导出中记录检验、重采样次数及依赖版本。图形、文本、明细表保留不同端点与滞后语义。
- 新示例：`examples/observational_nonlinear.csv`（X² → Y）；`examples/timeseries_nongaussian.csv`（X 的同期与一阶滞后影响 Y）。原有高斯示例不适合验证 RESIT / LiNGAM 的方向识别条件。

## 0.3 更新：导出结构图和结构文本

运行分析后，在“因果关系图”右上角点击 **“导出图与文本”**：

- **PNG 图片**：可直接插入 Word 或 PPT，导出完整画布，保留拖动后的节点布局。
- **SVG 矢量图**：可无损缩放，保留自定义布局。
- **TXT 结构文本**：列出完整变量名称、逐条关系、未定向/潜在混杂标记、滞后步长、可用统计量、算法条件和参数。
- **复制结构文本**：直接复制到剪贴板后粘贴使用。

右上角“导出结果包”同时包含 `graph.svg`、`structure.txt`、`edges.csv`、`result.json` 和 `report.html`。PNG 可通过图中菜单单独保存。导出历史分析前先在“历史与对照”中选择对应记录。

## 0.2 更新：可视化选择变量与拖动节点

- 在“数据与变量”顶部输入名称关键词进行搜索；多个关键词用空格分隔，匹配任意一个即显示。
- 用下拉菜单筛选数值、文本/类别、含缺失、已选、常数/空列。
- “选中筛选结果”和“取消筛选结果”仅操作当前显示的变量；切换筛选不会清除已选变量。
- 已选变量显示为标签，点击标签即可移除；最多选择 30 个。时间列不能作为时间序列分析变量。
- “只选数值变量”替换当前选择，“清空选择”取消全部变量。运行分析时变量选择暂时锁定。
- 在关系图中按住节点拖动，连线、箭头及滞后标注同步更新；空白处拖动平移，滚轮缩放。
- “重置布局”恢复自动排列。拖动仅调整图形位置，不改变边、方向、统计量或分析结果。
- 每次分析的布局独立保留在当前会话历史中。导出的 SVG、HTML 报告和 JSON 均保留自定义位置；关闭应用前请导出。

中文独立桌面应用，支持表格数据与单条时间序列的自动因果结构发现。所有分析在本机运行，无需账号或云端 API。当前版已接入九种真实算法，不使用相关系数阈值冒充因果发现。

## 立即启动

双击 `start.cmd`，或运行 `dist/CausalStudio/CausalStudio.exe`。分发时请复制整个 `CausalStudio` 文件夹，包括 `_internal`，不能单独复制 exe。使用便携版不需要安装 Python。

1. 选择“普通观测数据”或“时间序列”。
2. 导入 CSV、TSV、XLSX、DTA，或载入当前模式示例；Excel 可以选择工作表。
3. 在“数据与变量”中选择分析字段，排除 ID、索引、常数列及冗余总分。
4. 选择算法与参数。时间序列需要时间列，或明确确认行顺序为等间隔。
5. 运行分析；也可以依次运行同类算法，在“历史与对照”中查看差异。
6. 通过关系图、关系明细和分析说明解读结果。点击历史记录可查看及导出对应结果。
7. 导出 ZIP 结果包，包含 HTML 报告、SVG 关系图、TXT 结构文本、CSV 关系表和 JSON 配置。PNG 图片也可单独导出。导出不包含原始数据。

历史保留在当前会话内；更换数据或关闭应用之前，请导出需要保留的结果。

## 九种算法

| 算法 | 数据类型 | 当前实现 | 主要条件与输出 |
| --- | --- | --- | --- |
| PC | 独立样本 | PC-stable，Fisher-Z 或离散 G² | 无潜在共同原因；输出有向和未定向边 |
| FCI | 独立样本 | Fisher-Z 或离散 G² | 允许潜在共同原因；保留 PAG 的圆、尾和箭头端点 |
| GES | 连续独立样本 | 线性高斯 BIC 评分 | 无潜在共同原因；输出等价类，α 不参与计算 |
| DirectLiNGAM | 连续独立样本 | 固定随机种子，标准化数据 | 线性、非高斯、独立外生噪声、无潜在共同原因；显示结构系数 |
| PCMCI | 连续时间序列 | ParCorr / GPDC / CMIknn，滞后 1…τmax，BH-FDR | 平稳、等间隔、无潜在共同原因；发现滞后关系 |
| PCMCI+ | 连续时间序列 | ParCorr / GPDC / CMIknn，滞后 0…τmax，majority 规则 | 同期无环；输出同期等价类与滞后关系；本版不作 FDR 校正 |
| RESIT | 连续独立样本 | 随机森林 + HSIC | 非线性加性噪声、无潜在共同原因；输出连接 |
| VARLiNGAM | 连续时间序列 | 固定 VAR 阶数、标准化数据 | 线性非高斯独立噪声、同期无环；输出系数 |
| LPCMCI | 连续时间序列 | ParCorr / GPDC / CMIknn | 实验性；允许潜在共同原因，输出 PAG，不作 FDR 校正 |

Fisher-Z 及 BIC/ParCorr 有线性和分布方面的限制，不适合直接当作任意非线性关系的通用解法。离散 G² 仅供 PC / FCI 使用，要求每列 2–20 个类别；高维条件列联表可能非常稀疏。软件不会擅自把类别编码当作有序连续值。

普通示例由线性高斯模型生成，真实结构为：环境条件 → 中间响应 ← 设备输入，中间响应 → 输出响应，另有独立噪声。**此示例不满足 DirectLiNGAM 的非高斯识别条件**；其结果用来展示算法假设差异。`examples/observational_nongaussian.csv` 提供适合 LiNGAM 的非高斯链结构数据（X → Y → Z）。

时间序列示例真实滞后结构：输入信号(t−1) → 输入信号(t)，输入信号(t−1) → 中间响应(t)，中间响应(t−1) → 中间响应(t)，中间响应(t−2) → 输出响应(t)。

## 结果解释

- 有向箭头是算法假设下的方向约束；FCI / LPCMCI 的 PAG 有向边不一定表示直接效应。
- 无向边表示方向未识别；圆端点表示端点不确定。
- FCI / LPCMCI 双箭头表示潜在混杂结构，不表示两变量互为因果。
- 冲突标记保留算法的方向冲突，不强制改成箭头。
- ParCorr 显示偏相关、GPDC 显示残差距离相关、CMIknn 显示条件互信息；LPCMCI 显示搜索记录的统计量。DirectLiNGAM / VARLiNGAM 显示标准化结构系数；RESIT 只显示连接，不把邻接矩阵的 1 当作效应。它们不能横向直接比较，也不能直接当作通用干预效应。
- PC / FCI / GES 没有可简单解释为“每条边显著性”的单一 p 值，所以对应列留空。
- PCMCI 的 q 值是 BH 调整后的 MCI 检验值。PCMCI+ 的 p 值描述邻接关系，不检验同期方向。
- 算法间一致不等于证实因果；边数更多也不意味着算法更好。变量集、缺失处理或分析模式不同的结果不应直接比较。

## 数据处理和首版范围

- CSV / TSV / XLSX 首行必须是非空、唯一列名；DTA 直接读取变量名，不把首条观测当作表头。最多 512 MB、100,000 行、30 个选中变量。
- CSV 支持 UTF-8 / UTF-8 BOM / GB18030；TSV 用制表符；Excel 支持 `.xlsx`。旧 `.xls` 请先另存。
- 数值字段接受可完整解析的数值字符串；非有限数、常数列、完全或严重共线变量会被拦截。
- 连续变量在计算前标准化。离散变量采用类别编码，映射写入结果。
- 普通观测数据可选择完整行分析，报告删除行数及选择偏差提示。
- 时间序列有缺失时停止，绝不通过删行压缩时间。指定时间列时检查唯一性和等间隔，并按升序排序。
- 无时间列时无法验证采样间隔，需要使用者确认。滞后单位为采样步长，而非自动推断的小时或天。
- 不支持把多个受试者的面板数据直接拼成一条序列；不自动插值、不自动差分、不自动验证平稳性。
- 样本下限只是运行保护，不代表统计功效充分。大量变量和稠密图可能耗时很长，可随时取消计算。
- 首版未实现 bootstrap 稳定性、背景知识约束、干预效应估计和项目持久化；无向结果会如实保留。

## 开发和重新打包

开发环境为 Windows x64 / Python 3.14。`requirements-lock.txt` 保存实际验证的完整依赖版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe launch.py
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe launch.py --self-test output\selftest
.\build.ps1
```

自测会通过真实桌面工作流依次运行九种算法及六组非线性检验组合、导出结果、检查取消操作并生成截图。算法单元验证包含已知的独立样本碰撞结构、非高斯链、滞后因果结构及异常数据。模拟验证不保证在真实数据上恢复真值。

应用计算放在独立 Windows 子进程中，运行时界面可响应，取消和退出会回收计算进程。依赖安装后，正常分析和导出无需联网。
